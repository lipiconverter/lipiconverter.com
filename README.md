## What is Lipi Converter?

Lipi Converter is a free, browser-based tool for converting Nepali text between **Unicode** and **Preeti font** — instantly, with no installation required.

- ✅ Unicode → Preeti
- ✅ Preeti → Unicode
- ✅ Download as PDF or DOCX
- ✅ No ads, no tracking, works offline
- ✅ Handles complex conjuncts: क्ष, त्र, ज्ञ, श्र

> Built for Nepali writers, journalists, government professionals, and students who work with both modern Unicode and legacy Preeti font systems.
